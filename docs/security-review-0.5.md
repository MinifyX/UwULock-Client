# Security review, 0.5 (October 2026)

The fourth security review of UwULock, done before 0.5.0-beta.1 on 2 October 2026, over
everything new since 0.4.0-beta.3 (`origin/main` at `69b4a4e`): generator minimums, the next
one-time code, passkey details and deleting them, entry Sends (with the one-time code), UwU Sans
and the font setting, more Nyu, the password check's busy retries — in `uwulock-core`,
`uwulock-bitwarden`, `uwulock-wasm`, the desktop/phone app and the browser extension — and the
native passkey providers (`uwulock-authenticator`, `src-tauri/src/passkeys`, Android, Apple,
Windows, Linux). The server half is reviewed in UwULock Server's `docs/security-review-0.8.md`.

Severity as in 0.4: **High** is a secret leaving the device, or the server able to read or swap
a secret. **Medium** needs a hostile party (server, org member, page, app) or misleads the user
into leaking, but is real. **Low** is defence in depth. **Info** is worth knowing.

No Critical or High findings.
